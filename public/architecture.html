Hidden App — Architecture Diagrams

Expedition-tech platform for remote tourism in Colombia · PWA, Firebase/GCP, multi-agent AI ecosystem scoped by department

Production PWA Hackathon demo video Source code Architecture (Markdown)

Client (React 19 PWA + Capacitor), Firebase/GCP backend, ADK runtime with persistent sessions, the multi-agent expedition pipeline, MCP catalog server, Cloud Run Live voice worker and external telemetry APIs.

One chat turn: the hyperlocal agent loads its persistent ADK session (Firestore), queries the catalog on demand (MCP / FunctionTools, hermetically scoped to one departmentId), can invoke the Ranger as a tool (getLiveConditions) and checks real routes before answering with validated widgets.

Dedicated Trip Planner hub (/expedition/plan): department picker → 5-step wizard (step 2: mandatory groundMobility) → createExpedition enqueues a background pipeline. Four specialist ADK agents build the itinerary from verified catalog fichas (agent-only planningNotes), real Google Routes legs (max 45), coupon widgets, COP budget, mobility badge + expedition PDF — streaming live progress (queued → curating → routing → budgeting → writing → ready) to ExpeditionProgress via onSnapshot. Chat redirects multi-day trips here.

Trip ledger (/budget): solo trips are free; group trips require Premium (tripCode, owner/editor/observer roles). Expenses normalize to COP with optional USD/EUR entry using the daily official TRM cached in config/exchangeRates (getExchangeRates + scheduledExchangeRates). Group splits use paidByMemberId and splitAmong[]; balances appear in UI and in the bilingual generateTripPdf export. Offline: tripLedgerStore (IndexedDB outbox) syncs on reconnect; ledger routes bypass OfflineGuardian. Independent from the expedition planner hub.

One monitored destination: Ranger telemetry analysis every 15 minutes while the app is open, plus cloud cron push alerts for UV, AQI and rain thresholds.

Text agents (ADK)
chatAgent and environmentalAgent run on Google ADK — Agentic RAG, MCP catalog tools, persistent Firestore sessions, structured JSON.
Multi-agent expedition planner
createExpedition HTTP + onExpeditionCreate trigger: curator → logistics → budget → writer LlmAgents (Pro + Flash), deterministic catalog gathering, validated ids, coupon widgets, real driving legs. Hub at /expedition/plan.
Ranger as a tool
getLiveConditions fetches live weather/AQI/marine telemetry and delegates the tactical analysis to the Ranger sub-agent inside the chat turn.
Live voice
Cloud Run hidden-agent-worker + LiveKit + Gemini Multimodal Live (separate from the ADK text stack).
Off-Grid Vault
Department SQLite packs + local RAG on device — search and offline chat with zero network.
Trip ledger (Bitácora v2)
Solo/group expense tracking, TRM-backed multi-currency, group splits, IndexedDB offline outbox, bilingual PDF — decoupled from expedition planner.
